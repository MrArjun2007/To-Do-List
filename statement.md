# Project Statement

## Problem Statement
College students deal with college studies, assignments, revising, and other personal tasks. If the tasks are not arranged well, then it becomes very hard to track what needs to be done and what has been already done. In this project, I have designed a very basic command-line To-Do List Management system where I will be tracking the tasks within a program session.

## Scope
Tasks addition, display, deletion, marking as done, and counting-based summarization is allowed here. It is a single-user and in-memory program. Tasks do not remain once the program is closed. Features like login, reminder, due date, cloud synchronization, databases, and GUI are not part of this project.

## Target Audience
- College students
- Beginners who are learning Python and basic problem-solving skills

## Objectives
- Implementation of top-down design using meaningful modules.
- Implementation of algorithms, functions, conditionals, loops, lists, and dictionaries.
- Implementation of input and output based on menu.
- Handling of user inputs and validation for usual errors/operations.
- Maintain a nice-looking repository on GitHub with basic testing.## High-Level Features
1. Entry of task with a sequential ID for the present session.
2. Ability to view all, pending, and completed tasks.
3. Completion of a task.
4. Deletion of a task using ID.
5. Task totals and status counts.
